## 3. Detailed description（详细描述，中文，≥250 字符）

```
B站网页版的长视频不好找。

首页、搜索、分区、UP 主主页的推荐按兴趣排，不按时长排，想找二十分钟以上的内容只能挨个看每张卡片右下角的时长。这个扩展把这件事变成一眼可见：

· 时长前面加「短 / 中 / 长」标签，三档三种颜色
· 卡片描一圈同色边框，扫视时不用读数字
· 不想要的档位直接遮挡，页面布局不变形

【分类规则】

默认短视频为 5 分钟以下，中视频为 5 到 30 分钟，30 分钟以上算长视频。两个分界点都可以自己调，单位支持分钟，也可以切换成「分 + 秒」精确到秒。直播卡片单独识别成一档，橙标。

【过滤】

短、中、直播三档各有一个独立开关，默认只挡 5 分钟以下。

遮挡有两种形态，随时切换：
· 占位图遮挡：卡片位置和尺寸都保留，内容被一张图盖住，底部显示视频名和时长，图片底下仍是原链接
· 直接隐藏：列表里彻底不占位

【自定义遮挡图】

短、中、直播各有一组照片，组内轮流显示，每张卡片取下一张，不会满屏同一张图。照片在扩展弹窗里上传，支持一次多选，自动压到 800px 以内保证不占空间。没设置时用内置默认图，换电脑也不至于一片空白。

【临时放行】

被挡住的视频左键点一下就恢复，按住右键又挡回去。适合偶尔想看的，又不想为了它去关整个过滤开关。

【桌面小挂件】

页面右下角有一个可拖动的小角色，点它或者点旁边的「时」按钮展开快捷面板，里面是三个过滤开关和两个阈值拉杆。挂件拖到哪就停在哪，下次打开还在原地，面板会跟着它走。不需要挂件时在弹窗或面板里取消勾选「显示桌宠挂件」，页面就只剩标签和遮挡。

【关于隐私】

不收集任何数据，不联网，没有账号，没有统计，没有广告。只有 storage 权限，用来存你自己的开关、阈值和照片。全部在本机，卸载就没了。

【注意】

· 只作用于 bilibili.com 网页版，App 和小程序无效
· 时长来自页面已经显示的文本，扩展不额外请求接口
· B站改版导致选择器失效时，请在 Issue 里反馈页面地址
· B站自带的「检测到插件影响页面」横幅与本扩展无关，点掉即可
```

## 4. Detailed description（English，可选第二种语言）

```
Finding long videos on bilibili.com's web lists is tedious. Home, search, category and creator pages rank by interest, not by length, so you end up reading the tiny duration on every card.

This extension tags each card as short / medium / long with a colour and a coloured border, then lets you mask the tiers you don't want.

Features
· Duration tiers: default short is under 5 minutes, medium 5-30, long over 30. Both thresholds are adjustable, with second-level precision.
· Live streams are detected as a separate tier.
· Three independent filters (short / medium / live). Mask the cards with your own rotating images so the grid keeps its layout, or hide them completely.
· Each tier has its own photo group, shown in rotation. Images are uploaded in the popup, multi-select supported, downscaled to 800px. A built-in default image is used when you haven't set any.
· Click a masked card once to reveal that single video, right-click to mask it again.
· A draggable widget in the bottom-right corner opens a quick panel with the main toggles and both threshold sliders. Its position is remembered.
· Settings live in chrome.storage.local and apply to open tabs instantly.

Privacy
No data collection, no network requests, no account, no analytics, no ads. Only the storage permission. Everything stays on your machine.

Notes
· Works on the bilibili.com website only, not the mobile app.
· Durations are read from text already rendered on the page.
· If bilibili changes their markup and a tier stops working, please open an issue with the page URL.
```

## 10. Permission justification（权限理由）

| 权限 | 理由（英文界面直接填这段） |
|---|---|
| `storage` | 保存用户的过滤开关、时长阈值、自定义遮挡图片和挂件位置。没有这些设置扩展无法记住任何配置。 |
| `unlimitedStorage` | 用户上传的遮挡图片以 dataURL 形式存本地，默认配额放不下多张图片，需要解除配额限制。 |

如果审核追问 `unlimitedStorage`：可以说明"不使用该权限时，扩展只需存几 KB 配置；图片由用户主动上传，属于本地资源缓存，不上传、不联网"。如被要求移除，改为普通 `storage` 并把每组照片上限降到 20 张（800px JPEG 约 60–100KB/张）也能跑。

## 12. Notes for certification（给审核员的备注）

```
这个扩展只对 bilibili.com 网页版生效，需要在中国大陆可访问的网络环境下打开站点才能看到效果，建议使用 https://www.bilibili.com/ 首页测试（未登录也能看到视频卡片列表，不强制登录）。

测试步骤：
1. 安装后打开 https://www.bilibili.com/ ，页面右下角出现一个角色小挂件，旁边有「时」字按钮。
2. 首页视频卡片右下角的时长前面会出现「短 / 中 / 长」标签，卡片带一圈同色描边。
3. 默认开启「过滤短视频」（5 分钟以下），这类卡片会被一张灰色占位图盖住，底部显示视频名和时长。
4. 点击工具栏图标打开弹窗，可切换三个过滤开关、拖动两个阈值拉杆、上传自定义遮挡图。
5. 单击被遮挡的卡片会解除该卡的遮挡，右键单击恢复。
6. 点击右下角挂件或「时」按钮可展开页内快捷面板。

如果页面结构在审核时与描述不一致（B站前端更新频繁），请通过 Issue 联系，扩展不会因此产生任何错误弹窗或后台请求。

扩展不发起任何网络请求，无远程代码，全部逻辑在包内。

版本变更：1.5.3 —— 新增「显示桌宠挂件」开关（弹窗与页内面板均可切换，关闭时页面更干净）。1.5.2 —— 挂件面板跟随定位、左右键分离解除/恢复、照片组按档位独立轮换。
```

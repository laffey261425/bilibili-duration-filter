# 发布清单

两条线并行：GitHub 公开仓库 + Microsoft Edge 加载项商店。先发 GitHub（隐私政策必须有个公网 URL 才能提交商店）。

---

## 零、先处理的三个风险

### 1. `B站视频时长过滤扩展.pem` 是打包私钥

它跟 `.crx` 一起放在 `useing` 目录里。**私钥泄露等于别人可以用你的扩展 ID 发更新**。`.gitignore` 已经排掉，但推送前务必确认：

```bash
git status --short          # pem / crx / zip 都不该出现在列表里
```

`.crx` 和 `.pem` 是 Edge 本地打包生成的，商店提交用不上（商店只用 zip，签名由商店做），可以只留本地备份。

### 2. 名称里的「B站」

「B站」是哔哩哔哩的常用简称，属于第三方商标。商店审核一般不因此拒绝描述性引用，但如果被要求改名，用备选：`视频时长分类与过滤（B站版）`。改动时要同步改 `manifest.json` 的 `name` 和 `action.default_title`。

不要把名称写成「Bilibili 官方」「哔哩哔哩出品」这类暗示官方关系的说法，也不要放官方 logo。

### 3. `unlimitedStorage` 会被重点问

这是权限审查里比较敏感的一个。提交时必须在 Permission justification 里写清楚用途（见 `docs/商店文案.md` 第 10 节）。真被要求移除，改普通 `storage` 并把每组照片上限压到 20 张即可，功能不受影响。

## 一、打包 zip

商店只接受 zip，且**根目录必须直接是 `manifest.json`**（不能套一层文件夹）。注意别把 `.pem`、`.crx`、`.md` 打进去。

```bash
cd "D:/点子/网页b站视频过滤/useing/B站时长过滤扩展"
mkdir -p ../dist
python -c "
import zipfile, os
root = '.'
out = '../dist/bilibili-duration-filter-1.5.2.zip'
with zipfile.ZipFile(out, 'w', zipfile.ZIP_DEFLATED) as z:
    for base, dirs, files in os.walk(root):
        for f in files:
            if f.endswith(('.pem', '.crx', '.md', '.zip')):
                continue
            p = os.path.join(base, f)
            z.write(p, os.path.relpath(p, root))
print('done', out)
"
```

打完检查包内容（顶层应只有 manifest.json 和资源）：

```bash
python -c "import zipfile; [print(n) for n in zipfile.ZipFile('../dist/bilibili-duration-filter-1.5.2.zip').namelist()]"
```

期望输出里不应出现 `B站时长过滤扩展/` 这样的前缀层。

## 二、发 GitHub

1. 建仓库（建议名 `bilibili-duration-filter`，公开，不初始化 README，因为本地已有）
2. `useing` 目录作为仓库根：`git init` → `git add .` → 确认 `git status` 里没有 pem/crx/zip → commit → push
3. 仓库 About 区按 `docs/商店文案.md` 末尾的文案填 Description 和 Topics
4. 建两个 Issue 模板（可选）：`bug_report`（要求填页面 URL + 日期 + 浏览器版本）、`selector_broken`（B站改版专用）
5. 打 tag `v1.5.2`，Release 里附上 zip

推送前最后确认：

```bash
git log --stat -1
git ls-files | grep -Ei 'pem|crx' && echo "有私钥被跟踪，停下来" || echo "干净"
```

## 三、发 Edge 加载项商店

### 账号

- 用**个人 Microsoft 账户（MSA）**注册，工作/学校账户不支持
- 注册入口：https://partner.microsoft.com/dashboard/microsoftedge
- 免费，无上架费
- 账户类型（个人/公司）和国家/地区**注册后不可改**，选之前想清楚
- Publisher display name ≤50 字符

### 提交

1. Partner Center → Microsoft Edge → 新建扩展 → 上传 zip
2. 按 `docs/商店文案.md` 逐项粘贴：名称、短描述、详细描述、分类、搜索词
3. 传商店 logo（300×300 PNG，`icons/icon128.png` 可先用，条件允许重绘成 300）
4. 传截图：1280×800 或 640×480，最多 6 张（清单和每张内容见商店文案第 8 节）
5. 宣传图可选：小图 440×280、大图 1400×560
6. 填 Single purpose + 权限理由 + 数据处理声明（全选不收集）+ 隐私政策 URL
7. 填 Notes for certification（商店文案第 12 节，整段粘）
8. 提交审核

### 审核

- 首次审核最长约 7 个工作日
- 状态流转：In draft → In review → Waiting to publish → In the store
- 被拒先读拒绝原因，改完**必须提升 version 号**再提交，同版本重提会再次被拒

### 上架后

- 把商店链接补进 `README.md` 的「从商店安装」和 GitHub About 的 Website
- 商店里改了描述不需要重新审核代码，但更新包必须提版本号

## 四、下次更新流程（备忘）

1. 改代码，`manifest.json` 的 `version` 加一
2. 本地 `edge://extensions` 重新加载 + 刷新 B 站页面自测
3. 重新打 zip（文件名带新版本号）
4. GitHub：commit → tag → Release
5. Partner Center：Update → 上传新 zip → 写变更说明（这次改了什么）
6. README 的更新日志补一条

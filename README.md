# B站视频时长分类与过滤

给 B 站网页版加一层时长筛子：先把列表里每张视频卡按**短 / 中 / 长**标出来，再决定哪一档直接挡掉。

被挡掉的卡片不会塌成空白，而是盖上一张占位图（可以是自己的图，多张轮换），想看的点一下就恢复。默认只挡 5 分钟以下的视频，其余档位默认关着，谁都可以自己调阈值。

> 当前版本 **1.5.4**　|　Manifest V3　|　仅需 `storage` 权限　|　不联网、不采集任何数据

## 它解决什么问题

B 站首页和搜索页的推荐按你的兴趣排，不按时长排。想找点能看二十分钟的东西，得靠肉眼扫每张卡片右下角那串 `12:34`，扫一屏十几张，很累。

这个扩展把这件事做成一眼可见：

- 时长做成 **短 / 中 / 长** 彩色徽章（玫红 / 天蓝 / 绿），三档各一种颜色，卡片带同色描边
- 卡片描一圈同色边框，扫视时不用读数字
- 不想要的档位直接遮挡，页面布局不变形

## 功能

### 分类与标记

| 档位 | 判定 | 默认颜色 |
|---|---|---|
| 短 | 时长 < 短视频上限（默认 5 分钟） | 玫红 |
| 中 | 短视频上限 ≤ 时长 < 中视频上限（默认 30 分钟） | 蓝 |
| 长 | 时长 ≥ 中视频上限 | 绿 |
| 直播 | 卡片里没有时长、且带直播入口 | 橙 |

两个上限都可以自己改，单位支持分钟，也可以切成「分 + 秒」精确到秒。短视频上限始终小于中视频上限，输入冲突时自动夹到最近的有效值。

覆盖的页面：首页、分区页、搜索结果、UP 主投稿页、历史记录（能认 `00:04/29:26` 这种"已看/总长"格式，取总长）。

### 过滤（三级独立开关）

- **过滤短视频**（默认开）
- **过滤中视频**（默认关）
- **过滤直播**（默认关）

三档互不影响，可以只挡短、只挡直播，也可以全开。

被过滤的卡片有两种处理方式：

1. **占位图遮挡**（默认）：卡片位置和尺寸都保留，内容被一张图盖住，底部显示「视频名 · 时长」。图片底下仍是原来的链接，点击会穿透到视频（如果开了单击解除，则先用这次点击解除遮挡）。
2. **直接隐藏**：`display: none`，列表里直接不占位。

### 占位图与照片组

- 短、中、直播各自一组照片，组内**轮流显示**，每张卡片取下一张
- 照片在工具栏弹窗里上传，可一次多选；上传时自动压到宽 800px 以内（JPEG 0.82），透明 PNG 会先垫白底再压，不会变黑块
- 每组没设置照片时，用扩展内置的默认图（`placeholder.jpg`），换电脑也不至于一片空白
- 缩略图可单张删除，也可以整组清空

### 临时解除

- **左键单击**占位卡：这张卡恢复可见，直到刷新页面（解除状态按视频 BV 号记，同一视频在页面上重复出现也会一起恢复）
- **右键单击**：把刚才解除的卡片重新挡回去

### 页面右下角的桌宠

一个可拖动的角色小挂件（`pet.png`，想换图直接替换文件），旁边带个「时」按钮：

- 点角色或点「时」都能展开**快捷面板**，里面是三个过滤开关、显示视频名、显示占位图、显示桌宠挂件，以及两个阈值拉杆
- 面板会跟着角色走，拖到屏幕右侧就自动翻到左边，拖到下方自动往上收，不会跑出视口
- 拖动位置会记住，下次打开还在原地
- 不想要挂件时，在弹窗或页内面板里取消勾选「显示桌宠挂件」，挂件和面板会一起收起；想找回来点工具栏图标，在弹窗里重新勾上
- 照片组、单位这些不常用的设置在工具栏弹窗里

### 设置同步

所有开关和阈值存在 `chrome.storage.local`。弹窗里改完，已经打开的 B 站页面立刻生效，不用刷新；页内面板改完，弹窗下次打开也是新值。

## 安装

### 从商店安装

- Microsoft Edge 加载项商店：上架后补链接

### 本地加载（开发或未上架时）

1. 打开 `edge://extensions`（Chrome 是 `chrome://extensions`）
2. 打开左下角「开发人员模式」
3. 点「加载解压缩的扩展」，选 `B站时长过滤扩展` 文件夹
4. 打开任意 B 站页面，右下角出现桌宠即成功

**这个文件夹不能删、不能移动**，扩展读的就是该目录，删了会立刻失效。

改过代码之后要在 `edge://extensions` 里点一下「重新加载」，再刷新 B 站页面，否则跑的还是旧代码。

## 用法速查

| 想做的事 | 怎么做 |
|---|---|
| 只挡 3 分钟以下的 | 弹窗里把「短视频上限」拖到 3 分钟 |
| 换遮挡图 | 弹窗对应分组点「添加照片」，可传多张 |
| 让某台电脑默认就有图 | 把图改名成 `placeholder.jpg` 覆盖扩展目录里的同名文件，重载扩展 |
| 暂时放行一个视频 | 左键点它 |
| 把放行的重新挡住 | 右键点它 |
| 彻底不挡任何东西 | 弹窗里关掉三个过滤开关 |
| 不想看见桌宠 | 弹窗里取消勾选「显示右下角桌宠挂件」；挂件和面板会一起收起，恢复也在这里勾回来 |

## 工作原理

`content.js` 在 `document_idle` 注入 B 站所有页面，用 `MutationObserver`（300ms 防抖）监听 DOM，扫描卡片选择器命中的元素：

1. 从卡片里取时长文本 → 解析成秒（同时处理 `MM:SS`、`HH:MM:SS`、`MM:SS/MM:SS`）
2. 按两个阈值分类，把类名挂到卡片上，并给时长元素前面加标签文字
3. 如果该档位开了过滤且没被解除，就加遮罩类并注入占位图背景

遮罩不用 `visibility: hidden`，因为那样卡片里的链接就点不动了。这里用 `opacity: 0` 保留可点击性，再加一层 `pointer-events: none` 的背景图盖在上面。

## 已知限制

- **依赖 B 站当前的卡片类名**（`.bili-video-card`、`.floor-single-card` 等）。B 站前端改版后可能部分失效，需要更新选择器，Issue 里带上页面地址和日期即可
- 只作用于 `bilibili.com` 网页版，App、小程序、第三方客户端都无效
- 解除隐藏的状态不跨刷新，刷新后重新隐藏（这是有意的：解除只是临时放行）
- 只处理列表卡片，播放页内的推荐区、动态详情等位置没覆盖
- B 站检测到页面被扩展修改时会弹一条「建议加入插件白名单」的横幅，那是站点自己的提示，跟本扩展无关，点掉即可

## 隐私

不需要账号、不联网、不上传任何东西。只有两个权限：

- `storage`：存你的开关、阈值、遮挡照片和桌宠位置
- `unlimitedStorage`：照片以 dataURL 形式存在本地，默认配额放不下几十张，需要扩容

照片和设置都只在这台电脑这个浏览器里，卸载扩展就一起没了。详见 [PRIVACY.md](PRIVACY.md)。

## 目录结构

```
B站时长过滤扩展/
  manifest.json      MV3 清单，权限只有 storage / unlimitedStorage
  content.js         注入 B 站页面：分类、遮挡、桌宠、页内面板
  popup.html         工具栏弹窗界面
  popup.js           弹窗逻辑：阈值、单位、照片组
  placeholder.jpg    内置默认遮挡图
  pet.png            桌宠角色图（已抠透明底）
  icons/             16 / 48 / 128 图标
```

## 打包发布

商店只接受 zip，且 zip 根目录必须直接是 `manifest.json`（不能套一层文件夹）。

```bash
python tools/pack.py
```

脚本会读 `manifest.json` 里的版本号自动命名，输出 `dist/bilibili-duration-filter-<version>.zip`，同时排掉 `.pem` / `.crx` / `.md`，打完自己检查一遍顶层文件列表并确认 `manifest.json` 在根。

`*.pem`（打包私钥）绝对不要提交到仓库，`.gitignore` 已经排掉了。

## English

A Manifest V3 extension for the bilibili.com web player lists. It tags every video card as **short / medium / long** by duration, draws a colour-coded border, and can mask chosen tiers behind your own rotating images instead of collapsing the layout. Live streams are detected separately. Click once to unmask a single card, right-click to mask it again. Runs entirely offline with `storage` permission only — no account, no network requests, no data collection.
